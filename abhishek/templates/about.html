How it works (Course Details)

Data Structures & Algorithms-3 (25CS2103E) Course Project

This project demonstrates four advanced algorithm strategies to solve real-world e-commerce problems. All algorithms are implemented from scratch in pure Python.

Data Sources

The listings are generated from 3 real datasets:

  • cellphones_data.csv: Amazon and Best Buy US pricing.
  • flipkart_smartphones.csv: Real Flipkart listings.
  • gsmarena.csv: Global product models.
  • Note: A small number of listings (marked as 'simulated' source) were generated to guarantee near-miss edge cases for the algorithms to catch.

Course Outcomes (CO) Summary

CO Topic File What it does in simple words
CO1 Strategy Selection co1_strategy.py Looks at a problem's signature and picks the best algorithm to solve it.
CO2 Rabin-Karp Rolling Hash co2_rabin_karp.py Instantly finds identical text strings by turning words into numbers (hashes).
CO3 Bitmask DP co3_bitmask_dp.py Finds the cheapest seller combination for a cart by remembering subset costs instead of trying every possibility.
CO4 Edmonds-Karp Max-Flow co4_max_flow.py Treats sellers like water pipes with limits, and finds the maximum number of orders that can flow through them.

Why DP is better than Brute Force (CO3)

Trying every seller combination one by one takes 4ⁿ steps. Bitmask DP solves the same problem in n · 2ⁿ steps.
